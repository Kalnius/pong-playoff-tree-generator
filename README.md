# Table Tennis Playoff Form (Static App)

https://kalnius.github.io/pong-playoff-tree-generator/

The page displays the current group standings and playoff bracket, including
recorded match scores and winners. It is read-only.

## Prerequisites

- Node.js 20+

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Build output is generated in `dist`.

## GitHub Pages hosting

The included GitHub Actions workflow builds and deploys the app to GitHub Pages.
